# Baseball SQL Analysis Project

## Overview
This project analyzes baseball player careers using SQL. The goal is to understand how schools influence player success, salary trends, and career outcomes in professional baseball.

## Dataset
Data was sourced from baseball statistics database containing player, school, and salary information.

## Skills Used
- JOINs
- Window Functions
- CTEs
- Aggregations
- Ranking Functions

## 🛠️ Tools & Technologies  

- **SQL (MySQL)** — Core data analysis  
- **MySQL Workbench** — Query execution  
- **GitHub** — Version control & portfolio  
- **CSV Outputs** — Result presentation  

### Key Analyses:

#### 1. School & Talent Pipeline Analysis  
- Number of schools producing players per decade  
- Top 5 schools producing the most MLB players  
- Trends in talent production over time  

#### 2. Salary Analysis  
- Total and average salary by player  
- Identification of highest-paid players  
- Salary distribution insights  

#### 3. Career & Player Analysis  
- Career length evaluation  
- Player comparisons based on attributes  
- Trends in height and weight over time  

#### 4. Player Comparison Analysis  
- Players with similar characteristics (e.g. same birth date)  
- Distribution of batting preferences (right/left/both)  
- Team-level composition insights  

> All queries include comments explaining the business logic and purpose.

---

## Key Insights  

- Certain schools consistently produce a high number of professional players  
- Player physical attributes show trends across decades  
- Salary distribution is highly skewed toward top players  
- Team composition reveals patterns in batting preferences

# Baseball SQL Analysis Project

## Overview
This project analyzes baseball player careers using SQL. The goal is to understand how schools influence player success, salary trends, and career outcomes in professional baseball.

## Dataset
Data was sourced from baseball statistics database containing player, school, and salary information.

## Skills Used
- JOINs
- Window Functions
- CTEs
- Aggregations
- Ranking Functions

## Analysis Sections

### 1. School Analysis
Identified which schools produced the most MLB players and highest-performing athletes.

### 2. Salary Analysis
Analyzed salary distribution across players and identified top earners by school and career stage.

### 3. Career Analysis
Explored player longevity and career progression patterns using SQL aggregations and window functions.

### 4. Player Comparison
Compared players based on performance and salary ranking.
